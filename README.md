# Всем миром

Лендинг сервиса «Книга историй» и конструктор альбома.

```
index.html          лендинг: поводы, как это работает, подбор книги с расчётом цены, тарифы, вопросы
app/index.html      конструктор: сборка книги из папки, редактор, экспорт PDF
app/vendor/         face-api и веса модели распознавания (со своего домена, без внешних CDN)
```

Ссылки внутри лендинга относительные (`app/`), поэтому сайт одинаково работает
и на `*.github.io/<репозиторий>/`, и на своём домене.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки в корень.
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
3. Через минуту сайт открывается по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Свой домен

1. В DNS домена:
   - поддомен (`kniga.example.ru`) — запись `CNAME` на `<аккаунт>.github.io`;
   - корневой домен — четыре `A`-записи: `185.199.108.153`, `185.199.109.153`,
     `185.199.110.153`, `185.199.111.153`.
2. Settings → Pages → Custom domain — впишите домен, дождитесь проверки,
   включите Enforce HTTPS. GitHub создаст в репозитории файл `CNAME`.
3. Проверьте, что лендинг открывается на домене, а кнопки ведут на `домен/app/`.

Для российского хостинга (если ПДн должны обрабатываться в России — см. §8.2 ТЗ)
подойдёт любая раздача статики: положите те же файлы в корень сайта, структура не меняется.

## Что в лендинге демонстрационное

- Оплата не подключена: кнопка фиксирует состав заказа и контакт на самой странице.
- Разворот книги и лента участников — нарисованные примеры, не реальные данные.
- Цены и объёмы соответствуют ТЗ редакции 5: «Момент» 24–40, «Глава» 41–80, «Жизнь» от 81.
